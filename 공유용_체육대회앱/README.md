# 공유용 체육대회 앱

이 폴더는 다른 학교에 공유하기 위한 별도 앱입니다. 원본 앱의 파일은 삭제하거나 수정하지 않았고, 이 공유용 복사본에는 우리학교 Apps Script URL과 명렬 데이터가 들어있지 않습니다.

## 공유 전에 설정할 것

1. `js/config.js`를 열어 학교명, 행사명, 일시, 장소, 학년/반 목록을 새 학교 상황에 맞게 수정합니다.
2. 새 Google Sheets 파일을 만들고 `확장 프로그램 > Apps Script`를 엽니다.
3. `gas/Code.gs` 내용을 Apps Script에 붙여넣습니다.
4. `ADMIN_PASSWORD`와 `JUDGE_PASSWORD`를 실제 사용할 비밀번호로 바꿉니다.
5. Apps Script를 웹 앱으로 배포한 뒤, 발급된 배포 URL을 `js/config.js`의 `scriptUrl`에 붙여넣습니다.

## 대회 일정표 수정

`day.html`에 일정표를 직접 쓰지 않고, `js/config.js`의 `schedule` 배열에서 관리합니다. 행을 추가하려면 아래 형태를 복사해서 붙여넣으면 됩니다.

```js
{
  order: "4",
  time: "10:00~10:20",
  event: "경기명",
  participants: "참가 인원",
  sequence: "진행 순서",
  duration: "20분",
  note: "비고",
}
```

한 칸 안에서 줄바꿈이 필요하면 `"1학년\n2학년"`처럼 `\n`을 넣으세요.

## 명렬 시트 형식

새 학교의 Google Sheets에 `명렬` 시트를 만들면 참가 학생을 칩으로 선택할 수 있습니다. 이 시트가 없으면 학생 이름을 직접 입력하는 방식으로도 사용할 수 있습니다.
`명렬_샘플.csv`를 참고해 같은 열 구조로 붙여넣으면 됩니다.

| A열 | B열 | C열 | D열 | E열 |
| --- | --- | --- | --- | --- |
| 학년 | 반 | 번호 | 이름 | 성별 |
| 1 | 1 | 1 | 학생1 | 남 |
| 1 | 1 | 2 | 학생2 | 여 |

## 화면

- `index.html`: 학급별 참가 신청 화면
- `admin.html`: 관리자 신청 현황 화면
- `day.html`: 체육대회 당일 운영/심판 입력 화면

`scriptUrl`이 비어 있으면 명렬 조회와 제출은 연결되지 않습니다. 새 학교에서 반드시 자기 Google Sheets와 Apps Script를 새로 만들어 연결하세요.
